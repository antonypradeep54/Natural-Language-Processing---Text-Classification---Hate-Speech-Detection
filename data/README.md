# Dataset

## Dataset Source

The dataset used in this project is available on Kaggle.

**Download:** [Twitter Hate Speech — Kaggle](https://www.kaggle.com/vkrahul/twitter-hate-speech)

**Dataset filename:** `train_E6oV3lV.csv`

## Dataset Overview

| Description | Value |
|---|---:|
| Total tweets | 31,962 |
| Non-hate speech (Label 0) | 29,720 |
| Hate speech (Label 1) | 2,242 |

## Dataset Structure

| Column | Description |
|---|---|
| id | Unique tweet identifier |
| label | 0 = Non-hate speech, 1 = Hate speech |
| tweet | Original tweet text |

## Getting Started

1. Download the dataset from the Kaggle link above.
2. Extract the downloaded ZIP file.
3. Use `train_E6oV3lV.csv` to execute the Jupyter notebook in Google Colab.

The planned notebook will provide step-by-step instructions for loading, preprocessing, training and evaluating the dataset.

**Note:** The dataset is not included in this repository because redistribution permissions have not been verified.
